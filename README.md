# ⚽ Blue Lock Manga Reader

## 📱 Acerca de la App

**Blue Lock Manga Reader** es una aplicación no oficial para fans del manga Blue Lock. Permite leer todos los capítulos del manga, ver el anime, leer novelas ligeras y contenido spin-off como Episode Nagi.

### ✨ Características

- 📖 **Manga Completo** - Todos los capítulos de Blue Lock
- 🎬 **Anime y Live Action** - Episodios del anime y películas
- 📚 **Novelas Ligeras** - Historias complementarias de personajes
- 🏃 **Episode Nagi** - Manga spin-off de Seishiro Nagi
- 🔍 **Buscador** - Encuentra capítulos rápidamente
- 📱 **Modo Cascada** - Scroll vertical infinito
- 🔎 **Zoom** - Para ver detalles
- 🌙 **Modo Oscuro** - Interfaz completamente oscura
